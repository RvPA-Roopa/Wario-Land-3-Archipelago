# Transformation Commands

Transformations are performed after collecting their corresponding item by pressing Select + another button. 
**Select + Start** plays a sound effect and toggles between the two pages.
Press **Select** while transformed to return to normal.

## Page 1
| Button Combo | Transformation |
|---|---|
| Select + ⬆ | Puffy Wario |
| Select + ⬇ | Flat Wario |
| Select + ⬅ | Zombie Wario |
| Select + ➡ | Vampire Wario |
| Select + Ⓐ | Fat Wario |
| Select + Ⓑ | Fire Wario |

## Notes
Vampire Form is progressive. The first Progressive Vampire item will give you access to Vampire, but you will not be able to transform into Bat Form until obtaining the second Progressive Vampire item.

When a bat enemy touches you, you will directly transform into Bat Form. If you transform back with Ⓑ without two Progressive Vampire items, you will need to be touched by a bat in Normal Form again in order to access Bat Form.
